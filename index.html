Como o level.dat Gerencia Experimentos

O arquivo level.dat é um arquivo binário no formato NBT (Named Binary Tag). No Minecraft Bedrock e Education, os recursos experimentais são salvos na estrutura de tags abaixo:

// Estrutura NBT de Experimentos no level.dat
TAG_Compound(""):
TAG_Compound("experiments"): {
TAG_Byte("gametest"): 1 (Beta APIs)
TAG_Byte("upcoming_creator_features"): 1
TAG_Byte("experimental_custom_biomes"): 1
TAG_Byte("data_driven_jigsaw"): 1
TAG_Byte("cameras"): 1
TAG_Byte("experiments_evergreen_has_ever_been_toggle"): 1
}
TAG_Byte("hasBeenLoadedInCreative"): 1
Header do level.dat Bedrock

Diferente da Java Edition, no Bedrock o level.dat possui um cabeçalho de 8 bytes antes do bloco NBT comprimido em zlib (4 bytes de versão da estrutura + 4 bytes do tamanho do payload).

Marcação Permanente

Ao reescrever o campo experiments_evergreen_has_ever_been_toggle para 1, o jogo marca o mundo como experimental. Essa alteração impede que conquistas do Xbox Live sejam obtidas.

Procedimento de Teste de Mundos Convertidos

Siga este método seguro de teste isolado para validar scripts, estruturas e addons sem danificar seu save original.

1

Instalação Local Limpa

Importe o arquivo .mcworld gerado no Bedrock de forma isolada. Verifique se o nome contém a tag [Experimental] na lista de mundos.

2

Inspeção de Log de Scripts

Acesse Configurações > Criador > Ativar Registro de Conteúdo (Content Log). Entre no mundo e verifique se surgem erros de script em vermelho no canto superior esquerdo.

3

Validação de Componentes

Abra o inventário criativo ou use o comando /give @s namespace:item para conferir se os blocos e itens customizados do Addon estão carregando visualmente.

Como Interpretar Erros de Script no Content Log: Se o jogo disparar avisos informando que "import @minecraft/server" falhou ao carregar, significa que o experimento Beta APIs (gametest) não foi devidamente injetado ou o Bedrock utilizado está numa versão inferior à exigida pelo Addon.
